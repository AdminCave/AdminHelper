# Contracts: a changed path pulls in the checks that hold what it promises
# somewhere else. task-close.sh runs them before every commit (review.sh
# contracts --staged); a red one stops the close.
#
#   <glob> test <component> <test file>   verify.sh <component> --strict -- <test file>
#   <glob> pair <regex> <file> <file>     the first capture of <regex> is the same in both
#
# <glob> is a shell `case` pattern (`*` crosses `/`). <regex> is python and one
# word, so a blank inside a line is [^\S\n] (\s would cross a line break); it is
# searched over the whole file with ^ and $ per line. A pair touches both of its
# files, so it stands once for each. review_scripts_test.sh holds every line to
# the tree: the test file exists, the pair agrees today.
