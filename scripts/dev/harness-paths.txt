# harness-paths.txt — the files that make the harness what it is.

# Consumers: scripts/dev/hooks/harness-guard.sh (PreToolUse) refuses edits to
# these paths in an autonomous run; later stages reuse the list in their
# preflight. One glob per line, repo-relative, `#` starts a comment.
#
# Matching is shell `case` matching, where `*` also crosses `/`: a line ending
# in `/**` therefore covers the whole subtree, every other line is the file
# itself. Add a path here when changing it would change the RULES a run obeys —
# not merely because it is important.
